# Nebula-Launcher

Just a Minecraft: Java Edition launcher built with Electron and React.

## Highlights

- **Instances** for Vanilla, Forge, Fabric and NeoForge.
- **One-click Instances**: Performance, PvP, Shaders presets for a simple one click install.
- **Modrinth and CurseForge**: search, install with dependencies, identify installed files.
- **Modpacks**: install/update `.mrpack` and CurseForge packs, export `.mrpack` or full `.zip`.
